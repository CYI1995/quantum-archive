ABOUT THE COLLECTION

馆藏说明

这是一部以量子力学发展历程为主线的开放式数字档案馆，面向科学史阅读、物理教学与公众科普。

01 / SCOPE

内容结构

馆藏按四个阶段排列，每个历史节点为独立页面，呈现科学问题、时代背景、核心思想及实验进展。现有 31 篇基础卷宗可持续扩充。

02 / EDITING

如何修改文章

打开 GitHub 仓库中的 events/ 文件夹，选择事件的 .md 文件并点击铅笔图标。使用 Markdown 标题、文字、图片和 LaTeX 公式，提交后由 GitHub Pages 自动发布。

03 / SOURCES

学术使用

内容整理自量子力学发展年表，插图与演示为概念示意。关键历史细节、原始论文和实验结论应以可信学术来源进一步核对、补充与标注。

04 / DEPLOYMENT

极简技术架构

网站采用 GitHub Pages 内置 Jekyll 构建、Markdown 正文、Liquid 模板与本地 JavaScript。无需配置自定义 Actions、安装 Python 或维护依赖文件。
